<h2>Zomato Consumer Trends Analysis & Rating Prediction</h2>

<h3>Project Overview</h3>
<p>
This project analyzes a Zomato restaurant dataset containing over <b>50,000 records</b> 
to uncover consumer behavior, popular cuisines, pricing trends, and factors affecting 
restaurant ratings. The goal was to extract actionable insights and build machine learning 
models to support data-driven decisions in the food-tech industry.
</p>

<h3>Problem Statement</h3>
<ul>
  <li>Understand customer food preferences.</li>
  <li>Identify popular cuisines and price trends.</li>
  <li>Analyze factors affecting restaurant ratings.</li>
  <li>Build predictive models for ratings and customer preferences.</li>
</ul>

<h3>Data Preprocessing & Cleaning</h3>
<ul>
  <li>Handled missing values.</li>
  <li>Removed duplicate records.</li>
  <li>Standardized text fields (cuisines, locations).</li>
  <li>Converted columns to appropriate data types.</li>
</ul>
<p>
These steps improved overall data quality and reliability by <b>21%</b>.
</p>

<h3>Exploratory Data Analysis (EDA)</h3>
<ul>
  <li>Identified most popular cuisines.</li>
  <li>Analyzed price ranges preferred by customers.</li>
  <li>Studied relationship between cost and ratings.</li>
  <li>Detected location-based rating trends.</li>
</ul>

<h3>Data Visualization</h3>
<ul>
  <li>Built interactive dashboards using <b>Power BI</b>.</li>
  <li>Created analytical plots using <b>Python (Matplotlib & Seaborn)</b>.</li>
</ul>

<p>Key visualizations included:</p>
<ul>
  <li>Cuisine popularity charts.</li>
  <li>Rating distribution plots.</li>
  <li>Price vs rating analysis.</li>
  <li>Location-based restaurant trends.</li>
</ul>

<h3>Machine Learning Models</h3>

<h4>1. Regression Model</h4>
<ul>
  <li>Goal: Predict restaurant ratings.</li>
  <li>Target variable: Rating.</li>
  <li>Used regression algorithms to estimate expected ratings.</li>
</ul>

<h4>2. Classification Model</h4>
<ul>
  <li>Goal: Predict customer preference categories.</li>
  <li>Converted ratings into categorical classes.</li>
  <li>Used classification algorithms to identify high- and low-performing restaurants.</li>
</ul>

<h3>Tools & Technologies</h3>
<ul>
  <li>Python (Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn)</li>
  <li>SQL</li>
  <li>Power BI</li>
  <li>Machine Learning (Regression & Classification)</li>
</ul>

<h3>Key Insights</h3>
<ul>
  <li>Mid-range restaurants received the highest ratings.</li>
  <li>Certain cuisines consistently outperformed others.</li>
  <li>Higher customer engagement correlated with better ratings.</li>
</ul>

<h3>Business Impact</h3>
<ul>
  <li>Helped identify optimal pricing strategies.</li>
  <li>Revealed high-demand cuisines.</li>
  <li>Provided data-driven recommendations for restaurant performance improvement.</li>
</ul>
